# Password Strength Analyzer

A simple Python cybersecurity project that analyzes password strength.

## Features

- Checks password length
- Checks lowercase letters
- Checks uppercase letters
- Checks numbers
- Checks special characters
- Gives WEAK, MEDIUM, or STRONG result
- Provides suggestions for improving passwords

## Technologies Used

- Python
- Tkinter

## How to Run

1. Install Python.
2. Download this repository.
3. Open the project folder in VS Code.
4. Run:

python password_analyzer.py

## Project Purpose

This project demonstrates basic password security concepts and helps users understand how to create stronger passwords.
